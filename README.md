# Hypothesis-Testing-with-Men-s-and-Women-s-Soccer-Matches
## ⚽ Hypothesis Testing: Goals in Women’s vs Men’s International Soccer
- Overview
This project applies statistical hypothesis testing to determine whether the **mean number of goals scored** in women’s international soccer matches is the same as in men’s matches. The dataset includes **Official FIFA World Cup matches since 2002-01-01**, with the assumption that each match is independent (team form ignored).
